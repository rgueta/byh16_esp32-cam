Esta aplicacion (con de repositorio: byh16_esp32-cam ) es la que se genero para tomar las fotos que se utilizaran pora el
detector de placas, es el definitivo (tienen opciones:
  0.- Envio de fotos a: SD card o shared folder via http
  1.- Menu (serial terminal)
  2.- BT (configuracion y/o toma,envio de fotos [por comandos]).
  3.- Boton fisico para toma,envio de fotos.
